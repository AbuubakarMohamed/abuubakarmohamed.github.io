Featured project

FINAL-YEAR DISSERTATION · 2024

Outdoor Worker Location Tracker

A full-stack system for keeping track of people working in the field. Workers run an Android app that reports their location, and supervisors see everyone on a live map in a web dashboard.

Both clients share a Firebase backend, so updates from the phone show up on the dashboard without a refresh. Mapping is built on the Google Maps API.
